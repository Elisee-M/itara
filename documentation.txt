WHAT THIS PROJECT IS
--------------------------------------------------------------------------------
A mobile-first React + TypeScript app that controls an ESP32 "Home Lamp" over
the local network. The app is NOT hosted on the device: it is a standalone web
app, bundled locally and wrapped into an Android APK with Capacitor. It talks
to the ESP32 at http://192.168.4.1 once the phone joins the open "Home Lamp"
WiFi access point.

The phone is on an isolated AP with no internet, so the app is offline by
design: system font stack only, no CDN, no analytics, no web fonts, no remote
images, and no request of any kind outside the device. Every network failure is
turned into a calm human message, never a raw error string. The password is
never logged and never hard-coded.

Stack: React 19 + TypeScript + Vite 8. Lint: oxlint. Wrapper: Capacitor
(@capacitor/core, @capacitor/cli, @capacitor/android). No test framework and
no test directory exist in this project.

There is one permanent branding rule: the text "Made by Elisee" must appear at
the bottom of every screen. It lives in src/components/Footer.tsx and is never
removed or hidden.


HOW TO RUN
--------------------------------------------------------------------------------
  npm install          install dependencies
  npm run dev          Vite dev server
  npm run build        tsc -b && vite build   ->  writes dist/
  npm run lint         oxlint src
  npm run preview      serve the built dist/

  On Windows PowerShell, call npm as "npm.cmd" if script execution is disabled.

  Android debug APK:
    npm run build
    npx cap sync android
    cd android
    gradlew.bat assembleDebug
  (see README.md for GRADLE_USER_HOME and android\local.properties notes)


HOW THE PIECES CONNECT
--------------------------------------------------------------------------------
  index.html
      -> loads src/main.tsx
  src/main.tsx
      -> mounts <App/> (src/App.tsx) and imports the global stylesheet
  src/App.tsx
      -> owns ALL runtime state (status, unreachable, checked)
      -> polls getStatus() from src/api/lamp.ts every 4s while visible
      -> chooses exactly one of three views:
           ConnectionView  when !checked || (unreachable && status === null)
           DashboardView   when status.authenticated
           LoginView       otherwise
      -> always renders <Footer/> below the view
  src/api/lamp.ts
      -> the ONLY module that performs network I/O
      -> talks only to API_BASE (default http://192.168.4.1)
      -> normalises every failure into LampUnreachableError,
         and HTTP 401 into NotAuthenticatedError
  src/components/*.tsx
      -> pure presentational views; they receive data and callbacks as props
      -> they never fetch anything themselves

NETWORK RULES (enforced by review)
--------------------------------------------------------------------------------
  * Only src/api/lamp.ts performs network I/O.
  * The only host is the device: http://192.168.4.1 (or VITE_LAMP_HOST).
  * One request in flight at a time; status polls no faster than every 4s and
    never overlap.
  * No external fonts, CDNs, analytics or remote images anywhere.
  * The lamp password is typed by the user, never stored, never logged.
